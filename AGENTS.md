# PkmLens working rules

- Read PRODUCT.md, SPEC.md and STATUS.md before continuing.
- Stack: FastAPI + React 18 + TypeScript + Vite. Keep React on major 18.
- Work only in PkmLens. CardLens is a read-only source of reusable code/assets; do not stop its processes or reuse its user database.
- Preserve existing validation, permissions and error handling when reusing backend modules.
- UI reference: PokéBooth marketplace screenshots supplied by the owner. Warm light surfaces, orange accent, real card images, desktop filtering and usable mobile layouts.
- Live camera must use actual YOLO. Distinguish synthetic validation from real-camera evaluation.
- Use project-local Ponytail, UI UX Pro Max and Impeccable skills. Keep changes small and verified.
- Do not publish the site or activate real payments.
